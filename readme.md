# ვებპროექტი - პორტფოლიო

## აღწერა
ეს პროექტი წარმოადგენს თანამედროვე და რესპონსივ ვებგვერდს, რომელიც აწყობილია სემანტიკური HTML5, CSS3 და JavaScript ტექნოლოგიების გამოყენებით.

## მთავარი ფუნქციონალი
- სრულად ადაპტირებადი დიზაინი (მობილური, პლანშეტი, დესკტოპი).
- ინტერაქტიული ნავიგაციის მენიუ.
- კონტაქტის ფორმა ვალიდაციით.
